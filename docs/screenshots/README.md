# Application captures

These JPEGs are actual captures of PinjamLab 2.0 on 21 October 2026. The dashboard, catalogue, weekly planner and care views use fictional workspace accounts and records. Counts are illustrative software state, not a campus pilot or measured impact. The captures were copied without repainting UI text or values. Later runs create their own workspace state.

The editorial `../readme-cover.svg` is a purpose-made vector illustration, not an application capture or a photograph of university equipment.
